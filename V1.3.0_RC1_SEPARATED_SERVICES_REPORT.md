# AAK v1.3.0-rc1 separated services report

## Result

The gateway, resource verifier, isolated effect broker and durable audit anchor
now have explicit, testable contracts. Signed grants cross the gateway/resource
boundary using strict schemas. Provider credentials never appear in a gateway
grant, resource request, execution result or audit event.

## Failure semantics

- Invalid identity, policy, manifest, envelope, destination, replay, budget or
  wire data fails closed before provider execution.
- Authorization audit failure blocks the provider and requests quarantine.
- Provider failure produces a failure audit receipt and no committed outcome.
- Completion-audit failure after a successful provider call reports the effect
  as committed and requests quarantine, preventing blind retry.
- Simultaneous audit and quarantine failure is surfaced explicitly as a
  containment failure and is never reported as ordinary denial or success.

## Evidence

- 152 deterministic tests passed.
- 100 concurrent durable audit appends remained monotonic and chain-valid.
- 100,000 service-boundary mutations generated zero unauthorized acceptances,
  zero broker calls and zero crashes.
- The complete local defensive campaign passed after this change.

Docker was unavailable in the build environment. Therefore independent-host
deployment, live OPA/OIDC/PostgreSQL interoperability, network isolation,
database failover and external secret-manager evidence remain promotion gates,
not completed claims.
