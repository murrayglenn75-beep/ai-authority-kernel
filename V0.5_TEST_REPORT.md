## Remaining roots of trust

This validates a reference protocol in one Python process. It does not prove
that separate production services, IAM, networks or operators are configured
correctly. A fully compromised downstream resource owner can still alter its
own state. A coordinated attacker controlling the threshold quorum and the
downstream boundary can also authorize effects. Production assurance therefore
requires actual isolation, HSM/KMS keys, workload identity, off-account WORM
audit storage, durable serializable state, signed builds and independent
penetration testing.
