# AAK v1.1.0 rc1 Action Assurance report

## Scope

This release turns the local authority prototype into the first slice of a
provider-neutral Action Assurance Gateway for AI tool and API calls. It adds
contracts and local verification seams; it is not a production certification
or evidence from external identity, policy, database or cloud services.

## Added

- Universal canonical `ToolCall`
- Signed, versioned `ActionEnvelope`
- Signed, versioned `ToolManifest`
- Strict exact-field wire decoding for both signed contracts
- Strict MCP `tools/call` translation
- Strict REST method and route translation
- Downstream exact-action verification and atomic authority consumption
- Delegation, audience, protocol, manifest, effect and origin binding
- Deterministic SQLite connection lifecycle and Windows spawn compatibility

## Verification

- 133 deterministic unit tests passed with resource warnings promoted to errors
- 100,000 hostile envelope, request and manifest mutations
- Zero unauthorized acceptances
- Zero crashes
- One valid control accepted exactly once

## Residual gap

The test campaign is synthetic and local. Production readiness still requires
separate services, real workload identity, an external policy engine,
serializable shared state, credential isolation, network enforcement, durable
receipts, off-host audit anchoring, operational monitoring and independent
security review.
