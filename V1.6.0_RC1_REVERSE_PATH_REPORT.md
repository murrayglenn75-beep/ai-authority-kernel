# AAK v1.6.0-rc1 reverse-path security report

## Method

This review traced an external provider effect backward toward the model and
asked what forged artifact, ambiguous state or compromised interaction point
could still produce an unsafe effect or retry. It supplemented forward-flow
tests with a dedicated reverse-path mutation campaign.

## Confirmed defects fixed

1. **Parameter smuggling:** a manifest signed an input schema hash, but the
   gateway and broker did not execute a validator bound to that hash. Both now
   independently enforce an operator-owned `InputPolicy` whose schema hash must
   equal the signed manifest value.
2. **Schema configuration drift:** action-only validator registration could
   silently diverge from the signed schema. Startup/execution now fails closed
   on a hash mismatch.
3. **Ambiguous provider outcomes:** provider timeouts and malformed responses
   were called failures even though an effect might have committed. Outcomes
   now distinguish succeeded, definitively rejected before effect and
   ambiguous. Ambiguity quarantines the workload and forbids automatic retry.
4. **Lost broker responses:** a provider could commit while the broker response
   was lost. Any post-submission remote failure is now conservatively ambiguous.
5. **Missing reconciliation identity:** provider adapters now receive the
   signed transaction ID as `operation_id` for provider-side idempotency and
   later reconciliation.
6. **Audit receipt domain confusion:** receipts now sign an explicit anchor ID;
   a valid receipt from another environment is rejected even if a key was
   mistakenly reused.
7. **Audit rotation failure:** each audit row now persists its signing key ID,
   trusted overlapping verifiers preserve the historical chain, and signer
   rotation is atomic with concurrent appends.
8. **Exception normalization:** disallowed egress leaked a staging exception and
   caused 11,112 crash-class results in the first 100,000-case reverse run. The
   boundary now returns a stable denial; the repeated campaign had zero crashes.

## Evidence

- 218 deterministic tests passed.
- Seven 100,000-case adversarial campaigns completed with zero unauthorized
  effects or acceptances and zero crashes.
- The reverse-path campaign alone generated 100,000 mutations with zero broker
  or provider calls and zero unexpected exceptions.
- 310,000 resilience operations completed with zero unauthorized or duplicate
  effects and zero crashes.
- 1,653 HTTP operations preserved audit integrity with zero unauthorized or
  duplicate effects.
- Mutual TLS accepted the trusted identity and rejected unauthorized identities.

## Remaining external evidence gates

Docker and external infrastructure were unavailable. The release still needs
live multi-service deployment, enforced network policy, OPA/OIDC/PostgreSQL,
KMS/HSM integration, certificate rotation under traffic, database failover,
provider reconciliation drills, independent fuzzing and penetration testing.

The test totals demonstrate behavior only within the tested local model. They
do not constitute proof of general security or production certification.
